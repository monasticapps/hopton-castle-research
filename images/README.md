# Hopton Castle Images

Standardized copies from `images-raw/`. The raw image folder is unchanged. Wall letters have been remapped to the current A-B-C-D convention: old C = new A, old B = new B, old D = new C, old A = new D.

Folders:

- `exterior/`: outside views of walls and corners.
- `interior/`: inside views of walls and corners.
- `misc/`: satellite image, landscape, sign, boards, window view, and other non-wall images.

Naming pattern:

- `wall-A-outside-01.jpg`: wall A photographed from outside under the current A-B-C-D convention.
- `corner-AB-outside-01.jpg`: A/B corner photographed from outside, preserving left-to-right wall order under the current A-B-C-D convention.
- `corner-DC-inside-01.jpg`: D/C corner photographed from inside, preserving left-to-right wall order under the current A-B-C-D convention.
